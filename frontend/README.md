# LinkForge Frontend Single Page Application

Modern React 19 + Vite + TypeScript application with glassmorphism design system, Tailwind CSS, Framer Motion animations, Zustand state management, and Recharts interactive analytics.

## Tech Stack

- React 18 / 19
- TypeScript & Vite
- Tailwind CSS (Glassmorphism & Dark Mode)
- Zustand (Global Auth, Theme, and URL stores)
- TanStack Query (React Query)
- Axios Client with Token Auto-Refresh Interceptor
- Recharts (Analytics visualization)
- QRCode React (Client-side QR Code rendering and download)
- PapaParse (CSV Import and Export)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Setup Environment Variables:
   ```bash
   cp .env.example .env.local
   ```
3. Start Dev Server:
   ```bash
   npm run dev
   ```
